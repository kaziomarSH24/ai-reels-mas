# Project Context & Environment Notes (Snapclip Reels)

## Infrastructure
- **Server IP**: 52.140.120.55 (Azure)
- **Deployment**: We have a CI/CD pipeline (GitHub Actions) configured. Pushing to `main` automatically builds the Docker image (`kaziomar/snapclip-reels:latest`) and deploys it to the live server.
- **Docker Setup**: Local environment uses `docker-compose.override.yml` to mount local directories (e.g., `- .:/var/www`). Live environment pulls the image directly from Docker Hub.

## Known Issues & Fixes
- **yt-dlp Bot Detection**: Cloud IPs (Azure) get blocked. We rely on a `cookies.txt` file on the live server (`/var/www/storage/app/private/cookies.txt`). 
  - *Important*: Do not use `--extractor-args "youtube:player-client=android"` as it conflicts with cookie authentication.
- **Filament UI**: Using Filament v4 (Laravel 13). Forms must be typed as `Schema` (not `Form`), and use `->components()` instead of `->schema()`.

## Developer Preferences
- Fast resolutions, avoid unnecessary manual server steps if CI/CD can handle it.
